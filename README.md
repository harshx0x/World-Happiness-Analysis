# World Happiness Analysis 🌍

## Project Overview
World Happiness Analysis is a Python-based data analysis project that explores happiness scores across different countries in 2019.

## Objectives
- Identify the 10 happiest countries.
- Identify the 10 least happy countries.
- Calculate the average happiness score.
- Visualize country-level happiness scores.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Results
- Average Happiness Score: 5.41
- Highest Happiness Score: 7.769
- Lowest Happiness Score: 2.853
- Happiest Country: Finland
- Least Happy Country: South Sudan

## Visualizations
The project includes horizontal bar charts comparing the top 10 and bottom 10 countries.

## Project Files
- Jupyter Notebook: Complete analysis and Python code.
- Reports: Project report in Word and PDF formats.
- Screenshots: Evidence of project implementation.

## How to Run
1. Download the notebook.
2. Open it using Google Colab.
3. Upload the required dataset.
4. Run all notebook cells.
